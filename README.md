# HR Employee Analytics using Python

## Project Overview
This project analyzes employee data using Python to identify workforce trends, employee attrition, salary patterns, and department-wise insights.

## Tools Used
- Python
- Pandas
- Matplotlib

## Key Analysis
- Employees by Department
- Employee Attrition
- Overtime vs Attrition
- Average Salary by Department
- Age Distribution
- Job Role Distribution
- Gender Distribution
- Monthly Income Distribution
- Attrition by Department
- Highest Paying Job Roles

## Business Insights
- Research & Development has the highest number of employees.
- Employee attrition is approximately 16%.
- Employees working overtime are more likely to leave.
- Sales has the highest average monthly income.
- Sales Executive is the most common job role.
- Most employees are around 30 years old.
